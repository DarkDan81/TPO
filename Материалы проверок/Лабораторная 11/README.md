# Лабораторная 11 Чтение отчёта k6

Источник чисел — итоговый отчёт, встроенный в `Лабы/Лабораторная 11.docx`. Проанализирован 09.10.2026. Новый нагрузочный тест не выполнялся: эта лабораторная требует исследовать предоставленный результат.

- `report-k6.txt` — исходный числовой фрагмент с восстановленными переносами строк для чтения.
- `analysis.json` — значения, происхождение данных, SHA256 исходного задания, расчёты и проверка трёх требований.
- Командный DOCX и PDF находятся в `Готовые работы/`.

Условия из задания: поиск KnowBase, 3 минуты, максимум 50 активных виртуальных пользователей, последовательные запросы, одна проверка статуса на каждый ответ.

| Требование | Факт | Результат |
| --- | --- | --- |
| p95 < 500 мс | 620 мс | Не выполнено; превышение на 120 мс, или 24% относительно порога |
| Неуспешные HTTP-запросы < 1% | 0,60%; 60 из 10 000 | Выполнено |
| Успешные проверки ≥ 99% | 99,40%; 9 940 из 10 000 | Выполнено |

Итог — тест не пройден, поскольку один обязательный критерий нарушен. RPS 55,56 — среднее за тест, а не пик при 50 VU. Последнее значение vus = 2 и максимум 50 не доказывают постоянную нагрузку 50 VU все три минуты. Max 3,90 с подтверждает, что не все запросы укладывались в 620 мс. Конкретная причина задержек и точное количество запросов дольше 500 мс по агрегатам неизвестны.

В THRESHOLDS приведены два критерия. Требование проверок ≥ 99% выполнено по фактической сводке, но отдельный threshold для него в исходном фрагменте не показан. В отчёте предложено добавить `checks: ["rate>=0.99"]` для следующего запуска; это рекомендация, а не существующая конфигурация.

Для технического уточнения использована официальная документация [Grafana k6 Built-in metrics](https://grafana.com/docs/k6/latest/using-k6/metrics/reference/) и [Thresholds](https://grafana.com/docs/k6/latest/using-k6/thresholds/), дата обращения 09.10.2026. Все числовые значения исследуемого теста взяты из задания.

Распределение направлений между четырьмя участниками описано в отчёте. Это общий анализ предоставленных данных, не четыре независимых прогона.
