# Лабораторная 5 Тест дизайн DevMeet

Объект — собственный **учебный макет** небольшого сервиса регистрации на конференцию. Преподаватель разрешил выбирать форму; часть 3 задания разрешает выполнение на макете. Восемь полей и их ограничения сохранены из задания. Это клиентская валидация без backend, отправки и хранения заявок.

Скачайте `index.html` и откройте в браузере. Телефон вводится как строка из 10 цифр, поэтому начальный ноль сохраняется. Возраст — целое число полных лет. Две радиокнопки образуют одно логическое поле «Формат участия».

Числовая граница телефона трактуется как граница длины: минимальная и максимальная длина совпадают (10), проверены 9/10/11 без дублирования. У непустого промокода длина 8, проверены 7/8/9; пустое значение отдельно валидно. Для имени/фамилии проверены 1/2/3 и 49/50/51; для возраста 17/18/19 и 79/80/81. У Email и перечислений не выдуманы ограничения длины, отсутствующие в задании.

## Повторное выполнение

`check-form.cjs` выполняет действия интерфейса Playwright, сравнивает принятие и ошибки с подготовленными ожиданиями. Нужны Node.js и пакет Playwright; команды установки и запуска указаны в начале файла. По умолчанию новый журнал сохраняется в отдельную папку `lab5-rerun`, исходные доказательства не заменяются. Версия браузера при повторении может отличаться от исходной.

Окружение исходного прогона: Windows 11 Pro 10.0.22631, сборка 22631; Chromium 139.0.7258.5 headless; Playwright 1.51.1; viewport 1366 × 900 CSS px; масштаб 100%, DPR 1; en-US; Europe/Moscow. Снимки Test IT сделаны при 1600 × 1200 CSS px.

Проверки выполнены автоматизированно в общей сессии. Результаты записаны в ручной план Test IT под одной доступной учётной записью. В отчёте распределены направления между четырьмя участниками; четыре независимых ручных прогона не заявляются.

Успешные результаты относятся к выбранным данным и конкретному учебному макету. Соответствие всему RFC Email, безопасность, нагрузка, серверная обработка и все трёхфакторные взаимодействия не проверялись. Автоматизированная проверка собственного макета имеет ограниченную независимость от реализации, хотя ожидания зафиксированы отдельно до запуска.
